Nightreign Relic Organizer v1.13 Public Stable — ELDEN RING NIGHTREIGN の非公式・読み取り専用の遺物整理補助ツールです。
本ツールはセーブファイルを変更・保存しません。読み込んだセーブデータの解析はブラウザ内で行います。
色・深層判定・効果パラメータ、日本語名称、EffectGroupはHTML内に内蔵しています。解析・比較にネット接続は不要です。内蔵マスターの基準日は 2026-08-25 です。未知または名称未登録のEffect IDはID表示へフォールバックします。英語効果名は取得できた公式 en_US 名称を使用し、未収録IDは日本語名称へフォールバックします。
マスター更新時はコード内の MASTER_DATA_SNAPSHOT のみを新しい検証済みスナップショットへ差し替える構成です。
Export State / Import State では、解析済みの所持遺物・プリセット使用情報・不要マーク・条件付き上位互換の無視設定をJSONとしてバックアップ／復元できます。生のセーブファイル自体はJSONへ保存しません。

新しいセーブを読み込みますか？

新しいセーブをインポートしても、現在の「不要」マークは同じ遺物（GA Handle）が存在する限り維持されます。ゲーム側ですでに売却され、所持品から消えた遺物の不要マークだけ自動的に整理されます。セーブデータそのものは変更されません。
