# Changelog

## v1.13 — 2026-08-26

Initial public release of Nightreign Relic Organizer.

### Highlights

- Local, read-only NIGHTREIGN save parsing in the browser
- JA / EN interface
- Embedded relic/effect names and EffectGroup data
- Exact match / strictly outclassed / outclassed / conditional outclassed analysis
- User-defined ignored effects for conditional comparison
- Marked relic workflow and sale-oriented view
- Sale view aligned with the in-game relic selling screen for visual matching
- Preset usage indicators
- State export / import as JSON
- Embedded master data for offline use
- Content Security Policy with network connection APIs blocked
- GitHub Pages public web app

### Distribution

Recommended: use the GitHub Pages web app.

Offline use: download the standalone HTML attached to the v1.13 GitHub Release and open it directly in a browser.

The tool does not modify save data and does not upload loaded save data to an external server.
